# 上市公司审计模拟 ｜ 以五粮液（000858）2025 年度为例

用**公开财务数据**，完整走一遍年报审计的流程：
**了解被审计单位 → 识别与评估重大错报风险 → 设计进一步审计程序 → 执行分析性程序 → 形成审计意见**。

> **项目定位（先说清楚，避免误读）**
>
> 这是一个**审计方法论练习项目**。审计对象是真实上市公司，
> 数据全部来自公开渠道（新浪财经/巨潮资讯网/公司公告），
> 但本项目**没有、也不可能取得被审计单位的内部资料**
> （明细账、销售合同、出库单、凭证、经销商清单）。
>
> 因此：
> - **风险评估、程序设计、分析性程序**——真实完成；
> - **函证、存货监盘、凭证检查等细节测试**——仅完成**程序设计与底稿框架**，
>   未执行；
> - 出具的审计报告是**模拟练习稿**，不具法律效力。
>
> 本项目**不是**对天职国际会计师事务所审计工作的评价、复现或替代。

## 一、为什么选五粮液

2025 年五粮液发生了一件在 A 股罕见的会计事件，使它成为一个几乎"教科书级"的审计案例：

| 事件 | 内容 |
|---|---|
| 业绩 | 营业收入 **405.29 亿元，同比 −54.55%**；归母净利润 89.54 亿元，同比 −71.89% |
| 原因 | 公司对 2025 年业务模式进行梳理，**基于谨慎性原则调整部分业务的收入确认核算** |
| 实质 | 收入确认口径由「**发货即确认**」改为「**货物到达渠道终端并满足终端动销条件后确认**」 |
| 幅度 | 前三季度营业收入调减 **303.08 亿元**、净利润调减 **154.25 亿元**（追溯重述） |
| 罕见之处 | **第四季度单季营业收入为 −204 亿元** |
| 治理 | 董事长于 2026-02-28 因涉嫌严重违纪违法被立案审查调查并实施留置 |
| 审计 | 天职国际将「**营业收入的确认**」列为**关键审计事项（KAM）** |

**核心会计问题**：收入确认的**控制权转移时点**如何判断
（《企业会计准则第 14 号——收入》）。这属于**重大会计判断**，
正是审计中最需要职业怀疑、也最容易出问题的地方。

## 三、方法

### 3.1 风险评估（底稿 01、02）

在**财务报表层次**与**认定层次**两个层面识别风险，
并按审计准则区分一般风险与**特别风险**。

识别出两个**特别风险**：

| 特别风险 | 涉及认定 | 性质 |
|---|---|---|
| **营业收入的确认** | **截止** / 发生 / 准确性 | 重大会计判断 + **舞弊风险推定**（准则 1141） |
| **货币资金的存在性和完整性** | 存在性 / 完整性 | 余额 1,270.14 亿元，占资产总额 **66.86%** |

同时评估为**低风险**的项目：应收账款余额仅 **0.38 亿元**（白酒行业先款后货、
以预收为主）——据此把审计资源从"金额大的科目"转向"风险高的科目"。

### 3.2 分析性程序（底稿 04）—— 本项目唯一真实执行的程序

依据审计准则第 1313 号，四步走：
**建立预期值 → 确定可接受偏差 → 与实际值比较 → 调查重大差异**。

预期值取 2023–2024 两年均值；比率类可接受偏差设为 ±15pp。

| 比率 | 预期值 | 2025 实际值 | 偏差 | 判断 |
|---|---|---|---|---|
| 收现比 | 120.37% | **225.52%** | **+105.15pp** | ❌ 重大偏离 |
| 净现比 | 122.36% | **331.76%** | **+209.39pp** | ❌ 重大偏离 |
| 合同负债占收入比 | 10.68% | **33.21%** | **+22.53pp** | ❌ 重大偏离 |
| 毛利率 | 76.42% | 77.54% | +1.12pp | ✅ 正常 |

### 3.3 从分析性程序到结论的关键一步

管理层的解释（"调整了收入确认口径"）在方向上能说明全部异常，
但按准则第 1313 号，**询问所得的口头证据证明力最低**。
因此本项目得出的结论**不是**"收入没问题"，而是：

> **偏差超出可接受范围，不得仅依赖分析性程序得出结论，
> 必须执行细节测试**（检查合同条款、出库单/发票、年末截止测试、
> 结合合同负债对主要经销商函证）。

这一步是本科阶段最容易做错的地方 —— **把"分析性程序"当成结论，
而不是当作"决定下一步做什么"的信号**。

## 四、核心发现

### 发现 1：比率型指标会完全失灵

2025 年毛利率 **77.05% → 77.54%，仅变动 +0.49pp**，几乎是"完美稳定"的。
但同期营业收入腰斩、净利润跌掉七成。

原因是收入与对应成本**被同时剔除**（收入 −54.55%、成本 −55.51%），
比率因此**不受影响**。

> **结论**：只用比率做异常筛查，会**完全漏掉**本案这个最重大的异常。

### 发现 2：真正暴露问题的是"绝对额"和"勾稽关系"

| 类型 | 指标 | 本案表现 |
|---|---|---|
| 绝对额 | 营业收入、归母净利润 | −54.55%、−71.89% ✅ 暴露 |
| 勾稽关系 | 收现比（收现 ÷ 收入） | 114% → **226%** ✅ 暴露 |
| 勾稽关系 | 净现比（经营现金流 ÷ 净利） | 107% → **332%** ✅ 暴露 |
| 比率 | 毛利率 | 77.05% → 77.54% ❌ 失灵 |

**收现比升到 226%** 是最有信息量的信号：一个正常经营的年份，
收到的现金不可能达到收入的 2.26 倍 —— 除非**现金已真实收到，
但已不再被确认为收入**。这一条直接指向收入确认口径的调整。

### 发现 3：审计程序与专业机构高度一致

本项目从公开数据出发独立识别的两个**特别风险**，
与天职国际在审计报告中列示的两个**关键审计事项**一致；
设计的核心程序亦与报告披露的应对程序逐条对应。

> 这说明：**从公开信息出发、按准则的方法论推演，是能够识别出
> 专业机构认为最重要的事项的。** 这正是本项目想训练的能力。

## 五、局限（必须诚实说明）

1. **无法执行细节测试**：没有合同、凭证、经销商清单，函证与监盘无法进行，
   因此本项目**不能**对财务报表是否不存在重大错报发表结论。
2. **数据为第三方口径**：来源于新浪财经接口，未直接解析巨潮资讯网原始年报，
   存在数据商口径差异的可能。已用审计报告披露的
   「货币资金 1,270.14 亿元、占资产总额 66.86%」做**交叉验证**，一致。
3. **预期模型过于简化**：仅取前两年均值，未使用回归模型或行业基准；
   偏差阈值（±15pp / ±20pp）为经验设定，未做敏感性分析。
4. **仅覆盖五粮液单一样本**，未做同业对比。
5. **报告为模拟稿**，不具法律效力。
