# 底稿 02 ｜ 重大错报风险的识别与评估

> 审计准则依据：中国注册会计师审计准则第 1211 号（识别和评估重大错报风险）、
> 第 1141 号（财务报表审计中与舞弊相关的责任）
> 底稿编号：C2　编制人：吴宝源

---

## 一、风险评估总体思路

在**财务报表层次**和**认定层次**两个层面识别风险，并确定哪些属于**特别风险**。

认定（Assertions）含义速查：

| 认定 | 含义 |
|---|---|
| 发生 | 记录的交易确实发生，且与被审计单位相关 |
| 完整性 | 所有应当记录的交易均已记录 |
| 准确性 | 交易金额及其他数据已恰当记录 |
| **截止** | 交易已记录于**正确的会计期间** |
| 分类 | 交易已记录于恰当的账户 |
| 列报 | 已恰当汇总并描述 |

## 二、财务报表层次的风险

| # | 风险 | 影响 |
|---|---|---|
| 1 | 行业深度调整，公司业绩大幅下滑（营收 −54.55%、归母净利 −71.89%） | 管理层面临**业绩压力与扭亏/保增长动机**，整体舞弊风险上升 |
| 2 | **董事长被纪委监委立案审查调查并留置**，治理层出现真空 | 公司治理失效风险；管理层凌驾于控制之上的可能性上升 |
| 3 | 发生**重大前期会计差错更正**，需追溯重述各季度数据 | 说明原有财务报告流程存在重大缺陷，**整体控制环境存疑** |
| 4 | 期末货币资金占资产总额 66.86%，资产高度集中于单一科目 | 一旦该科目错报，对财务报表整体影响重大 |

> **结论**：财务报表层次风险处于**较高水平**。应按准则要求：
> ① 在**整个审计过程中**保持职业怀疑；② 对**管理层凌驾于控制之上**
> 实施专门的审计程序；③ 增加**不可预见性**（unpredictability）的程序安排。

## 三、认定层次的重大错报风险

### 风险 1（★特别风险）营业收入的确认 —— 截止 / 发生 / 准确性

| 项目 | 内容 |
|---|---|
| 涉及账户 | 营业收入、合同负债、其他流动负债、发出商品、应收账款 |
| 涉及认定 | **截止**（核心）、发生、准确性 |
| 风险描述 | 公司本期将收入确认口径由「发货即确认」改为「货物到达渠道终端并满足终端动销条件后才确认」。**控制权转移时点的判断属于重大会计判断**，存在两种错报方向：<br>① **提前确认**：为做高业绩，在未满足确认条件时即确认收入；<br>② **推迟确认**：本期已通过更正调减，需关注是否存在**过度谨慎**、把应确认的收入递延至以后期间（形成"利润蓄水池"）。 |
| 风险性质 | **特别风险**（涉及重大判断 + 舞弊风险推定） |
| 舞弊风险推定 | 按审计准则第 1141 号，**应当推定收入确认存在舞弊风险**。本期叠加董事长被立案调查事件，该推定不可推翻。 |
| 支持性证据 | ① 毛利率几乎不变（77.05% → 77.54%），但营收腰斩 → 说明是**口径调整**而非经营变化；② 销售商品收到的现金 914.00 亿元，远高于营业收入 405.29 亿元；③ 第四季度营业收入为 **−204 亿元**；④ 合同负债由 116.90 亿元增至 134.60 亿元。 |

### 风险 2（★特别风险）货币资金的存在性和完整性

| 项目 | 内容 |
|---|---|
| 涉及账户 | 货币资金 |
| 涉及认定 | **存在性**、**完整性**、权利和义务 |
| 风险描述 | 期末余额 1,270.14 亿元，占资产总额 **66.86%**，金额极其重大。需关注：① 银行存款是否真实存在；② 是否存在**未披露的质押、冻结或受限资金**；③ 是否存在**大额资金占用、违规担保或资金体外循环**（在治理层异常、董事长被调查的背景下，该风险显著上升）。 |
| 风险性质 | **特别风险**（金额重大 + 舞弊风险） |
| 支持性证据 | 货币资金占总资产比三年稳定在 66.86%–69.79%，未见异常波动；但与治理层异常事件叠加，仍需保持高度职业怀疑。 |

### 风险 3 存货的计价与分摊（存货跌价准备）

| 项目 | 内容 |
|---|---|
| 涉及账户 | 存货 |
| 涉及认定 | **计价与分摊**、存在性 |
| 风险描述 | 存货账面价值由 182.34 亿元增至 200.65 亿元（+10.04%），同时成品酒库存量同比 **+45.18%**。行业存在"渠道库存高企、价格倒挂"。**在收入确认口径收紧、终端动销放缓的背景下，存货是否存在减值迹象、跌价准备计提是否充分**，存在重大估计不确定性。 |
| 风险性质 | 重大错报风险（涉及重大会计估计） |

### 风险 4 合同负债 / 其他流动负债的完整性与准确性

| 项目 | 内容 |
|---|---|
| 涉及账户 | 合同负债、其他流动负债 |
| 涉及认定 | **完整性**、准确性、分类 |
| 风险描述 | 合同负债由 68.64 亿元增至 134.60 亿元；媒体报道该口径调整使"待确认收入的预收款项"在三季度末增加超 270 亿元。需关注：已收款未确认收入的部分是否**完整、准确**地计入负债，是否存在**少计负债、多计收入**；以及该负债在未来期间的**结转时点**是否恰当。 |
| 风险性质 | 重大错报风险 |

### 风险 5 应收账款 —— 评估为低风险

| 项目 | 内容 |
|---|---|
| 涉及账户 | 应收账款 |
| 涉及认定 | 存在性、计价与分摊 |
| 风险评估结论 | **低**。应收账款余额仅 0.38 亿元，且三年均稳定在 0.37–0.43 亿元区间。 |
| 判断依据 | 白酒行业对经销商普遍执行**先款后货**，销售以预收（合同负债）为主，赊销极少。因此**应收账款函证不作为本项目重点**，审计资源应投向收入确认时点与合同负债。 |

> **这一判断本身是审计资源分配的关键**：把有限的审计资源投向
> "金额小但风险高"的收入确认，而不是机械地对大科目全面铺开。

## 四、风险汇总表

| # | 风险事项 | 涉及认定 | 评估水平 | 是否特别风险 |
|---|---|---|---|---|
| 1 | 营业收入的确认（控制权转移时点） | 截止 / 发生 / 准确性 | **高** | ★ 是 |
| 2 | 货币资金的存在性和完整性 | 存在性 / 完整性 / 权利义务 | **高** | ★ 是 |
| 3 | 存货跌价准备（计价与分摊） | 计价与分摊 | 中 | 否 |
| 4 | 合同负债完整性与准确性 | 完整性 / 准确性 / 分类 | 中 | 否 |
| 5 | 应收账款 | 存在性 / 计价与分摊 | **低** | 否 |
| 6 | 管理层凌驾于控制之上（报表层次） | 整体 | **高** | ★ 是 |

## 五、对后续审计工作的影响

1. 对**特别风险**（收入确认、货币资金），**不能仅依赖分析性程序与内部控制**，
   应当**实施实质性程序**获取充分、适当的审计证据；
2. 对**收入确认**，实质性程序应包含**细节测试**（检查合同、出库单、发票、
   截止测试）与**函证**（对主要经销商，同时函证本期收入与合同负债余额）；
3. 全部程序应体现**不可预见性**（如扩大截止测试的抽样范围、
   对非惯常交易单独检查）；
4. 需就**管理层凌驾于控制之上**设计专门程序（如检查重大会计分录、
   复核会计估计的偏向性）。
