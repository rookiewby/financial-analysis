# 食品饮料行业上市公司财务分析（SQL）

用 Python 采集 A 股食品饮料行业 **25 家上市公司 2023–2025 年**的年度利润表，导入 MySQL，
再用 SQL 完成**盈利能力、成长性、费用结构、异常波动筛查**四个维度的分析。

项目重点不在"算了多少指标"，而在**从数据里筛出了什么异常，以及为什么单一指标会漏判**。

---

## 一、数据

| 项 | 说明 |
|---|---|
| 样本 | 食品饮料行业 25 家 A 股上市公司 |
| 行业覆盖 | 白酒 / 啤酒 / 软饮料 / 乳制品 / 调味品 / 休闲食品 / 肉制品 |
| 期间 | 2023、2024、2025 三个完整年度（年报） |
| 记录数 | 25 家 × 3 年 = **75 条** |
| 来源 | 新浪财经，经 akshare `stock_financial_report_sina` 接口获取 |
| 数据校验 | 与同花顺 `stock_financial_abstract_ths` 交叉比对，关键指标完全一致 |
| 金额单位 | 元（SQL 内统一除以 `1e8` 转为亿元） |

> 数据源选型说明：本项目最初使用东方财富接口，因该接口不稳定切换为新浪财经，
> 并保留同花顺作为**第二数据源做交叉验证**，避免"单一数据源的错误无法被发现"。

## 五、分析维度

| # | 分析内容 | 使用的 SQL 技术 |
|---|---|---|
| 1 | 数据体检（记录数、缺失值） | `GROUP BY` + `SUM(条件)` |
| 2 | 2025 年毛利率排名 | 窗口函数 `RANK() OVER` |
| 3 | 毛利率 → 净利率的损耗 | 复合表达式 |
| 4 | 近三年营收同比增速 | 窗口函数 `LAG() OVER (PARTITION BY)` |
| 5 | 2023→2025 营收 CAGR | CTE + 条件聚合 |
| 6 | 费用结构（三费 + 研发费用率） | 多列比率计算 |
| 7 | 行业中位数 | `ROW_NUMBER()` + `COUNT() OVER()` 自实现（MySQL 无内置中位数） |
| 8 | 毛利率异常波动筛查 | `HAVING` 过滤聚合结果 |
| 9 | 增收不增利筛查 | CTE + 多条件交叉 |
| 10 | 营收异常波动筛查 | `LAG` + `ABS()` 双向阈值 |

## 六、核心发现

### 1. 行业盈利能力严重分化，均值会失真

2025 年毛利率：**均值 47.59%，中位数 40.22%，极差 17.26% ~ 91.34%**。

均值比中位数高出 7 个百分点，原因是高端白酒（茅台 91.34%）把均值显著拉高。
**用均值描述这个行业的"典型水平"会失真，中位数才是更稳健的行业基准。**

### 2. 高毛利不等于高净利，费用结构才是分水岭

以「毛利率 − 净利率」的差额衡量费用与税负对利润的侵蚀程度：

| 公司 | 毛利率 | 净利率 | 差额 |
|---|---|---|---|
| 贵州茅台 | 91.34% | 47.85% | 43.50pp |
| 五粮液 | 77.54% | 22.09% | 55.45pp |
| 古井贡酒 | 79.26% | 18.85% | **60.41pp** |
| 水井坊 | 79.85% | 13.36% | **66.48pp** |

白酒普遍毛利率 70%~85%，但**销售费用率高达 27%~29%**，把毛利砍掉大半。
只有茅台是例外——它靠品牌而非渠道驱动。

### 3. 两种截然不同的商业模式

| 模式 | 代表 | 销售费用率 | 研发费用率 |
|---|---|---|---|
| 品牌驱动 | 贵州茅台 | 4.22% | 0.11% |
| 渠道驱动 | 古井贡酒 | **28.98%** | 0.47% |
| 产品驱动 | 恒顺醋业 | 16.50% | **4.11%** |

研发投入最高的是恒顺醋业（4.11%）和安琪酵母（4.05%），而茅台仅 0.11%。

### 4. 增长分化：三年里只跑出一个高增长公司

2023→2025 营收 CAGR：

- **东鹏饮料 36.14%**（断层第一）
- 安琪酵母 10.97%、山西汾酒 10.12%、海天味业 8.43%、贵州茅台 6.90%
- 尾部：五粮液 -30.24%、洋河股份 -23.85%、水井坊 -21.69%、良品铺子 -17.43%

25 家中仅 10 家实现正增长，行业整体处在收缩周期。

### 5. 异常波动筛查：单一指标会漏掉重大异常（核心案例）

第一版筛查规则只看**毛利率同比变动 ≥ 5 个百分点**，全样本只命中 1 家（洽洽食品 -5.37pp）。

**但它完全漏掉了五粮液**——2025 年营收同比 **-54.55%**，而归母净利润同比 **-71.89%**，
是行业里最重大的异常，毛利率却几乎没变（77.06% → 77.54%）。

原因经核对原始公告确认：五粮液于 2026-04-30 发布《关于前期会计差错更正的公告》，
对 2025 年部分业务的**收入确认核算**作出调整，收入与成本**同比例下调**，
因此毛利率这个"比率型指标"完全失真，而"绝对额型指标"（营收、净利）才暴露问题。

补充第二版规则（**营收同比变动 ≥ ±20%**）后成功定位，同时筛出：
水井坊 -41.77%、洋河股份 -33.47%、中炬高新 -23.90%、良品铺子 -23.38%、古井贡酒 -20.13%。

> **结论：分析性程序必须多维度交叉。比率型指标和绝对额型指标各有盲区，
> 只做一层筛查一定会漏掉重大异常。**

补充：本案例中，五粮液审计机构（天职国际）在 2025 年报审计报告中
将"**营业收入的确认**"列为关键审计事项（KAM），
其披露的审计程序之一即为"结合产品类型对收入以及毛利情况执行分析，
判断本期收入金额是否出现异常波动"——与本项目的筛查思路一致。

### 6. 其他异常

- **增收不增利**：安井食品（营收 +7.05%，净利 -8.46%）、涪陵榨菜（营收 +1.88%，净利 -3.92%）
- **净利率为负**：光明乳业 -0.62%、良品铺子 -2.69%

## 七、局限与改进方向

1. **样本有限**：仅 25 家，未覆盖食品饮料全部上市公司（约 100+ 家）。
2. **仅用利润表**：未纳入资产负债表与现金流量表，缺少营运资本类指标
   （应收账款周转、存货周转、销售收现比等）。
3. **未做同业对标基准**：异常阈值（±20%、5pp）为经验设定，
   更严谨的做法是按行业细分（白酒/啤酒/乳制品）分别设定阈值。
4. **数据源为第三方**：未直接解析巨潮资讯网原始年报，存在数据商口径差异风险。

## 八、复现步骤

```bash
# 1. 建库
mysql -u root -p -e "CREATE DATABASE finance DEFAULT CHARSET utf8mb4;"

# 2. 采集数据并入库（会提示输入 MySQL 密码）
python fetch_data.py

# 3. 执行全部分析查询
python run_sql.py
```

依赖：`akshare`、`pandas`、`sqlalchemy`、`pymysql`、`cryptography`
